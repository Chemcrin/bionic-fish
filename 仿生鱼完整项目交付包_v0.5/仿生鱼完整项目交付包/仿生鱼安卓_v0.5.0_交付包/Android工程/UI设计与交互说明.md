# v0.5.0 UI 设计与交互说明

采用 Kotlin、Jetpack Compose、Material 3、单 Activity 与导航；网络、协议、重连和完整控制目标均在 UI 外管理。

## 1. 页面与信息层级

| 页面 | 主内容 |
| --- | --- |
| 设备 | AP 热点直连常驻卡、系统 Wi-Fi 设置入口、LAN/Mock 发现、连接进度与错误。 |
| 控制 | 连接状态，M1/M2 独立方向组，±15° 舵机，回传状态和固定底栏双路急停。 |
| 状态/调试 | 两路固件方向、兼容 RPM（NA）、舵角、姿态、延迟、最后更新、故障与本地日志导出。 |
| 设置 | 独立 AP/LAN 参数、通信时序、两路反向开关、安全停止与减少动态效果。 |

## 2. 双电机与停止

- M1 标明“370 直流减速（主推进）”，M2 标明“N20（唧筒·沉浮）”；各有推、停、拉三个按键（推进侧即前进/停止/后退），不提供连续 PWM 或 RPM 滑杆。
- 挡位由 `step_speed` 承载：`60` = 低速挡（60% 占空比）、`100` = 满速挡（95% 占空比），来自配套固件的 2 s 慢周期双挡位方案；界面不将其当作测速结果。
- 单路按键仅修改一路，保留另一路及舵机目标；显式模式持续运行，松手即停模式松开只停当前一路。
- 底部“立即安全停止”始终可达，**不加阻碍紧急停止的二次确认**；同时停止 M1/M2，按配置回中或保留舵角，并显示 ACK 等待/失败状态。
- 导航离开、后台和断开按保存策略双停；重连不恢复旧方向。网络急停失败必须提示，不能把本地目标当成确认停机。
- 新安装允许两路反向；升级保留旧关闭偏好。关闭时按钮说明去设置启用并保存；保存关闭反向前先双停。
- 已取消旧步进参数确认对控制的阻挡；`stepperParametersConfirmed` 仅兼容存量状态，不再阻挡 M1 或 M2。

## 3. 舵机与状态

预设为左 -15°、中 0°、右 +15°；滑杆范围 -15..15，`steps=29`，共 31 个整数位置。拖动只更新本地预览，松手提交最终值；选中态与无障碍播报同步到 ±15°。

界面区分“本地目标”与“固件回传”：m1/m2 缺失为未知，非法值不刷新状态；step_on 仅 M1，不拿它推 M2。RPM/姿态 NA 明确标未知；超时显示数据过期。servo 是命令角，不是实际舵面传感器读数。接收旧 ±30° 状态不扩大新操控范围。

旧故障 bit4 解释为历史步进门禁；非零故障不等于解析失败，但必须保持可见。

## 4. 组件与无障碍

沿用 4dp 间距体系、浅/深色语义主题、按钮/方向组/滑杆/状态徽标/提示条/空状态；关键动作使用文字和状态语义，不只依赖颜色。

小屏通过自适应分组和滚动承载内容；底栏双停独立于内容滚动。关键控件至少 44dp 触控目标，支持系统 200% 字体。TalkBack 触摸探索开启时自动用显式停止，避免按住操作无法释放。减少动态效果配置不影响安全操作。

本版自动 UI 测试、模拟器截图及尺寸覆盖以 [构建验证报告](artifacts/v0.5.0构建验证结果.md) 为准。真实 S24、TalkBack 人工走查、完整横竖屏/平板、对比度测量和系统动画偏好仍待实测；未提供的 `UI设计RP.md` 不被宣称已逐条移植。
