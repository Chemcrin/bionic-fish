# v0.5.0 验收检查清单

范围：新 Android 工程和 APK；不改写 STM32/ESP，不以用户文档中的固件实测描述代替本机证据。

## 1. 本机交付证据

本版构建、lint、JVM/UI 测试执行数量与结果、APK 元数据、签名、SHA-256、截图均以 [v0.5.0 构建验证结果](artifacts/v0.5.0构建验证结果.md) 为准。下表“已实现/有测试”只表示代码和用例已落地，是否实际通过请查报告；不沿用 v0.4.0 历史统计。

| 项目 | 实现与检查依据 |
| --- | --- |
| 版本与工程隔离 | v0.5.0 / code7，原 v0.4.0 不覆盖；构建依赖冻结，debug 签名。 |
| 完整双路命令 | CMD 尾随 m2；M1/M2 独立 F/R/S，单路操作保留另一完整目标；协议/仓库测试。 |
| 双路安全停止 | 明确 move=S,m2=S；回中/保留角、后台、离页、断开、换设备与重连路径检查。 |
| 单路优先停止 | 只停一路，避免误作全局急停；不因普通控制节流吞掉停止。 |
| 舵角边界 | UI ±15、steps=29、命令拒绝±16；STA 独立接收±30兼容旧固件。 |
| 回传方向 | 可选m1/m2缺失为未知，非法/重复拒收；step_on仅M1，NA不填0。 |
| 握手 | 同seq ACK+link=1 STA，400ms同序号双停保活，超时/取消清理。 |
| 反向设置 | 新装true，旧false保持；设置同时约束两路，关闭前双停；持久化测试。 |
| AP直连 | 原Wi-Fi专用路由与独立配置保留，不扫描AP，不伪造蓝牙或RSSI。 |
| Mock与旧帧 | 双方向组合、m2缺省停止、粘拆包/非法帧、旧STA/NA/err等协议回放。 |
| UI | 两组控件、±15标签/选中态/语义、固定停止栏、过期状态与深浅主题。 |
| 隐私 | 本地日志主动导出，无默认上传；未增加未使用的危险权限。 |

## 3. 放行限制

模拟器、Mock、单元测试不能证明电机实际方向、舵角、供电或水中安全。先卸载危险负载并备妥立即断电，再做台架联调；无线停止不是硬件急停。旧APK ±30°按钮与新±15°固件不兼容，应安装新版。

AP参数已有用户资料来源但未本机复测；普通LAN/UDP发现与蓝牙UUID仍待确认。协议不加密且无设备身份认证，不可将握手通过解读为强身份认证。
