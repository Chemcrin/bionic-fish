# 安装这个 APK：BionicFish-v0.5.0.apk

版本 0.5.0 / code7，应用名“仿生鱼控制台”，大小 20,270,434 字节。桌面同名 APK 与交付包根目录 APK 完全相同，只需安装一次。

1. 将 `BionicFish-v0.5.0.apk` 作为原文件传到手机，完整保存后打开。文件后缀必须为 `.apk`，不是 `.zip`、`.apk.1`、`.bin` 或下载未完成的文件。
2. 安装 APK，不要打开 Android工程文件夹来找安装程序；项目 ZIP 仅用于保存源码和资料。
3. 安装后先用“设置 → 模拟设备”检查两路按钮，再连接真实鱼端热点。手机中的安装来源许可由你按系统提示确认，本次未更改手机安全设置。
4. 如系统拒绝安装，保留完整错误提示截图再排查；不要先删除旧版。签名冲突时卸载旧版会丢设置和本地数据，应先备份。本包与工作区 v0.4.0 签名一致，三星 S24 实机尚未验证。

本版：M1=370、M2=N20 各自前进/后退/停止；底部“立即安全停止”同时停止两路；舵机 -15° / 0° / +15°。两路占空比由配套固件固定，手机没有调速滑杆。

新装默认允许反向，升级保留旧设置。如果后退按钮禁用，在“设置”开启“允许电机反向”并保存。

AP 参数来自用户资料：先手动连接 `BionicFish-AP`，初始密码 `12345678`，再在应用连接 `192.168.4.1:9000`；设备参数若已修改，以实物为准。没有蓝牙连接功能。

仅更新安卓 APP，未修改 STM32 / ESP / 网页固件。使用前确认鱼端已是双直流电机、±15° 的配套版本；旧 42 步进固件不能视作兼容。先做受控台架测试，不直接带负载下水。

源码、构建脚本、107 项单元测试与 28 项模拟器测试证据、界面截图位于 `Android工程/`。详细结果见 `Android工程/artifacts/v0.5.0构建验证结果.md`。
