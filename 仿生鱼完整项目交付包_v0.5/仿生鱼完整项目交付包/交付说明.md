# 仿生鱼当前交付说明

2026-09-09 工作区修订：最终系统为 STM32F103C8T6 + ESP-01S AT/TCP + Android；HarmonyOS 暂停。本轮没有发布新 GitHub Release。目录中的 v0.3.1/v0.3.0 名称为既有归档名称，组件可以独立版本化。

## 有效入口

- `STM32控制工程/`：固件源码、固定依赖构建脚本、主机回归测试和当前硬件/协议说明。按该目录 README 构建后使用 `build-firmware/` 的产物及哈希记录。
- `仿生鱼安卓AP直连_v0.3.0_2026-09-06/Android工程/`：Android 源码，当前版本 0.3.2（versionCode 5）。设备页 AP 直连使用 Wi-Fi 专用 TCP Socket。
- 同级 `仿生鱼控制器_v0.3.0_AP直连.apk`：历史版本，不能当作本轮固定低速版本的产物。新 APK 以 Android `app/build/outputs/apk/debug/` 为准。
- `原始资料/`：板级输入资料，其中历史设想不覆盖当前代码和配置。

## 当前范围

两路直流减速电机（M1 = 370 主推进、M2 = N20 12V 版）分别使用 TB6612 的两个 H 桥，各自独立启停与换向；一路舵机（安全行程 ±20°），JY61P 姿态和 SSD1306 单页显示。按键暂不使用。HarmonyOS/ESP32 WebSocket 或自定义 ESP 透明桥不在本轮链路；旧透明桥保留在 STM32 legacy/，不参与当前构建/烧录。

**host 侧 17/17 通过（10 个可执行 + 7 个编译期门禁）。**—**Arm 交叉构建尚未重做：下面这段 BIN 尺寸/哈希属于改动前的旧固件，双直流电机版本必须重新构建后以新产物为准。**（原文）固定低速版本通过17/17 CTest和Arm交叉构建，BIN24,604字节；Android0.3.2/code5通过56/56单元测试和23/23 MuMu设备测试，lint0错误，APK20,389,118字节。最终产物及哈希见STM32 build-firmware/build-info.json和Android验证记录。

默认推进为**满占空比（100%）**运行：M1、M2 各自独立方向，无换相节拍；STOP、失联、接收丢失或发送故障时两路同时 coast。100% 是开环满压设定，**不是限流或过流保护**（TB6612 无过流保护规格），必须实测电流与温升。安卓端需按交付方案升级后才能控制 M2。
