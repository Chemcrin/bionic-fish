# v0.5.0 ESP-01S AP 直连

本版保留 Wi-Fi TCP 直连，新增双电机独立方向与±15°舵机；没有重新烧录或改写 STM32/ESP。ESP-01S 不是蓝牙设备。

## 1. 参数来源

初始值来自 [用户AP指引](原始资料/AP直连_安卓端修改指引.md)，不是本机实测：

| 项目 | 指引值 |
| --- | --- |
| SSID / 初始密码 | BionicFish-AP / 12345678 |
| TCP 端点 | 192.168.4.1:9000 |
| 桥接 | ESP AT 1.7.4 + STM32 AT / +IPD |
| USART2 / 回传周期 | 115200 / 约200ms（设备配置，不是APK测量） |

用户后续资料称 AP+STA 双模；其中192.168.3.40仅为现场LAN示例，不是默认IP。实际设备已改配置时以实际值为准。AP参数独立保存，不覆盖LAN参数；AP不需要UDP发现。

## 2. 手机上操作

1. 传输并安装 `BionicFish-v0.5.0.apk` 或中文双电机15度副本，确认完整后缀是`.apk`，不是ZIP或测试APK。
2. 先确认配套双直流电机固件，解除危险机械负载并准备立即断电。若已连接其它设备，先安全断开。
3. 应用“设备”页打开系统Wi-Fi设置，手工加入 `BionicFish-AP`；无互联网提示选择保持连接。
4. 返回应用，核对 `192.168.4.1:9000`，点“连接仿生鱼热点”，不用扫描。实际端点不同则先修改AP专用设置。
5. 等待双停CMD收到同seq ACK及有效STA，才视为握手完成。先检查两路停止，再分别操作M1/M2及舵机。
6. 新装默认可反向；升级后如果后退未启用，去设置打开“允许电机反向（M1/M2均生效）”并保存。
7. 操作结束先底部“立即安全停止”，再安全断开。单个“M1停止”或“M2停止”不会替另一电机停止。

连接示例：

```text
<CMD,seq=12,move=F,turn=L,step_speed=60,servo=-15,m2=R>\n
```

这是完整目标，M1前进、M2后退、舵机左15°；step_speed不是手机调速。全局急停为move=S,m2=S，默认回中。真实方向与舵角须在台架确认。

## 3. 网络与失败处理

AP TCP Socket使用匹配目标IPv4本地子网的Wi-Fi，不回退移动数据/VPN，不依赖互联网验证；它不读取或验证SSID，也不能阻止手机主动切走热点。手机系统自动切网导致断开时，先重新加入正确热点再重连。

TCP失败先查热点、IP/端口和供电；TCP成功但握手失败，查日志中的同seq ACK与link=1 STA，再查AT/+IPD桥接。NA转速、非零err可解析，不应靠放宽握手条件掩盖缺帧。400ms同序号双停握手保活保留；ACK默认800ms，后续STA窗口2000ms。

旧固件未报m1/m2时显示未知，不能拿step_on推M2；旧固件若返回反向/步进门禁错误，检查烧录版本，本次APK没有代改固件。关闭或失去Wi-Fi时停止帧可能送不到，必须验证MCU约1000ms无有效CMD的双停逻辑。

## 4. 证据与未实测

本轮未连接三星S24、ESP或STM32；安装、无互联网热点稳定性、真实双路/±15°动作与失联停机仍待实测。自动测试和签名结果见 [v0.5.0报告](../artifacts/v0.5.0构建验证结果.md)，不沿用历史数字。

日志在状态/调试页主动导出，最多500条内存记录，退出进程可能丢失。网络协议无加密/强认证，热点和控制设备应由用户确认。系统级±15°仍需核对固件与网页同时限角。
