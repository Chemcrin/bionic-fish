## 4. 联调边界

- 本版适配 M1=370（尾段推进）、M2=N20（唧筒活塞）两路直流电机，不再提供步进 RPM 滑杆。配套固件为 **2 s 慢周期 + 95%/60% 双挡位**，APK 侧 `step_speed=60/100` 切换低速/满速挡。
- 实际硬件入口为 Wi-Fi TCP AP 直连。BionicFish-AP、初始密码 12345678、192.168.4.1:9000 来源于用户 AP 指引；ESP 当前值、实际 AT/+IPD 链路待确认。ESP-01S 不提供蓝牙。
- 仅更改 Android。STM32、ESP、网页未随本 APK 一并改动或烧录；V1.0.0 已确认双电机（含 N20 唧筒）与 ±15° 限角在固件侧实装。
- 新安装默认允许两路反向，升级保留用户之前明确关闭的设置。需反向时在设置中开启并保存。
- 无编码器。m1/m2 为固件目标方向而非实测转速；缺失字段显示未知，NA 不伪装为 0。
- 三星 S24 安装、AP 无互联网/移动数据共存、机械方向/电流/舵角、真实超时停机均未实测。无线停止帧不能保证在断链后送达，必须验证配套固件失联处理。

建议下一步：先核对板上双直流电机固件和 ±15° 版本；手机安装后先验证 Mock，再在备妥立即断电的受控台架上逐路测试 AP 连接、方向、各自停止、双停、舵角和断网停机。
