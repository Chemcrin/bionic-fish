## 核心参数（改这里就能调形）

全部集中在 `modeling/model.py` 顶部：

```python
L_TARGET = 700.0     # 总长，最后等比缩放到这个值
THICK    = 3.2       # 壳体壁厚（说明书建议 2.5–4）
NX, K    = 232, 34   # 纵向站数 / 每象限截面点数（网格密度）

#      鼻尖 x=0 ................................................ 尾尖 x=712
XS   = [0,   14,  35,  70,  105, 154, 210, 280, 350, 420, 490, 560, 616, 658, 700, 708, 712]
WID  = [1.5, 18,  40,  66,  86,  108, 126, 134, 131, 123, 112, 98,  82,  66,  44,  28,  2.0]  # 半宽
ZTOP = [118, 134, 155, 182, 203, 224, 238, 240, 236, 229, 218, 202, 184, 166, 146, 139, 134]  # 上缘
ZWL  = [114, 112, 112, 114, 117, 120, 123, 125, 125, 125, 125, 126, 128, 131, 134, 135, 133]  # 最宽线
ZBOT = [110, 92,  76,  60,  50,  41,  35,  34,  34,  36,  40,  50,  66,  90,  120, 128, 131]  # 下缘
NUP  = [...]   # 上半截面超椭圆指数，越大越"方"
NLO  = [...]   # 下半截面指数，取 3.5–3.7 得到说明书要求的"平面或浅凹底板"
```

改完跑：

```bash
python modeling/build.py
```

`--no-render` 可跳过预览渲染（几何生成本身 <0.1 s，渲染约 20 s）。

## 建模假设（说明书未给定，需要复核）

说明书原话："除草图上约 700 mm 长度、约 300 mm 高度外，其他尺寸均应视为比例参考。"
以下数字是我按图推的，不是视频给的：

1. **翼展 421 mm** / 机身最大宽 263 mm —— 由 358–362 s 俯视 CAD 的目测比例反推。
2. **壳厚 3.2 mm** —— 取说明书建议区间 2.5–4 的中值。
3. **翼面位置** 弦向 175–486 mm（占全长 25–69%），根弦 283、梢弦 156、下反 18 mm。
4. **双灯** ⌀44 mm，轴心 y=±39、z=33，装在机腹前缘下方 —— 说明书说"位于前下方"且"装在
   底部前缘的短支架上"，所以做成略低于腹线、能看见支架的形式。
5. **推进器** 尾部左右护罩 ⌀98 mm、中央轴向护罩 ⌀92 mm。视频只给了形态没给尺寸。
6. **把手** 拱高约 60 mm（从上壳算起），弧顶即整机最高点 —— 草图的 300 mm 是含把手的总高。
