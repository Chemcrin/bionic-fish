# ① 硬件制造

**目标**：得到一台能安全通电、能被电脑识别、各模块可独立替换的裸机。

**完成标志**：上电后 PC13 指示灯每 500 ms 翻转；Type-C 接电脑能在串口助手里看到输出；XT60 供电正常、两轨电压分别正确。

---

## 二、电路与接线

### 2.1 电源链路

```text
XT60（主）/ 咪头（备）
        │
        ▼
  5 A 一次性保险丝
        │
        ▼
   LM2596S（DCDC 可调）
        │
        ├──────────────► 动力轨：TB6612 的 VM、舵机
        │
        └──────────────► 5 V 中间轨
                              │
                              ▼
                        ME6211（LDO）────────► 3.3 V 逻辑轨
                                                STM32 / ESP-01S / JY901S / OLED / CH340
```

**为什么分两轨**：LDO 干净但效率低，给 mA 级、怕纹波的逻辑器件；DCDC 有开关纹波但效率高，给 A 级、不在乎纹波的动力器件。**JY901S 对电源纹波敏感**，若用 DCDC 直供 3.3 V，电机启停会让姿态数据出现难以定位的跳变。

详见 [电源方案与电压汇总.md](../../电气设计说明/电源方案与电压汇总.md)。

### 2.2 引脚接线

| 功能 | STM32 引脚 | 接到 |
| --- | --- | --- |
| M1 PWM | `PA0` | TB6612 `PWMA` |
| M2 PWM | `PA1` | TB6612 `PWMB` |
| M1 方向 | `PB12` / `PB13` | TB6612 `AIN1` / `AIN2` |
| M2 方向 | `PB14` / `PB15` | TB6612 `BIN1` / `BIN2` |
| 舵机 | `PA6` | 舵机信号线 |
| ESP 通信 | `PA2` / `PA3` | ESP-01S `RXD` / `TXD`（**交叉**） |
| CH340 调试 | `PB10` / `PB11` | CH340 `RX` / `TX`（**交叉**） |
| JY901S I²C | `PB6` / `PB7` | 模块 `SCL` / `SDA`（**需 4.7 kΩ 上拉到 3.3 V**） |
| OLED I²C | `PB8` / `PB9` | 模块 `SCL` / `SDA` |
| 调试按键 | `PB0` / `PB1` / `PA8` | K1 / K2 / K3 |
| 运行指示 | `PC13` | 板载 LED |
| SWD | `PA13` / `PA14` | SWDIO / SWCLK |

**接线要点**：

- **TB6612 的逻辑电源接 3.3 V**，电机功率电源接动力轨（约 12 V）；逻辑地与功率地**必须共地**。
- **两条软件 I²C 互相独立**：`PB6/PB7` 是 IMU 总线，`PB8/PB9` 是 OLED 总线，排查时不要互相推断。
- **一路 I²C 一路诊断**：`I2CSCAN` 报 OLED 总线、`IMUSCAN` 报 IMU 总线。
- ESP-01S 的 `RST` / `EN` / `IO0` / `IO2` **悬空即可**，不要误接到 STM32。
- **电机端绝不能直接接 STM32 GPIO。**

### 2.3 三条接线纪律

1. **上电前用万用表确认 XT60 极性。** 保险丝不防接反，接反会击穿所有模组。
2. **两轨不得共用细走线或窄地回流路径。** 若出现「电机一动、IMU / OLED 就异常复位」，首要怀疑逻辑轨被动力轨污染。
3. **先调好 LM2596S 输出再接负载。** 直接用电池接电机，若 DCDC 输出未调对会超压。

## 三、结构件制造

### 3.1 尾段零件（已开源）

可发布的尾段零件在仓库根目录 [`鱼尾装配/`](../../鱼尾装配/README.md)，含 SolidWorks 原生件与 STEP 交换格式。

| 类别 | 文件 | 状态 |
| --- | --- | --- |
| 承载支撑 | `尾部左支撑V6F.step`、`右支撑V4F.step` | **当前版本** |
| 传动 | `套筒.SLDPRT`、`摇杆.SLDPRT`、`moto shef.SLDPRT`（电机座） | **当前版本** |
| 连接 | `U型件.SLDPRT`、`鱼体第二关节.step.SLDPRT` | **当前版本** |
| 快拆 | `快拆架.SLDPRT`、`防水盒快拆.SLDPRT` | **当前版本** |
| 装配参考 | `尾部装配2.SLDASM` | 参考装配 |

> ⚠️ `右支撑V2.SLDPRT` 与 `测试装配.SLDASM` 是**历史版本**，仅作对比，**不要用于打印**。

**打印参数建议**：

- 支撑件是主要承力件，材料用 **PETG**，**壁厚不低于 3.2 mm，填充率 40% 以上**。
- 关节与快拆件**先试打印单件**确认配合间隙，再批量打印。
- 部分零件的装配间隙与止口需根据实际打印精度微调。

### 3.2 外壳

外壳为**参数化建模**产物（Python 型线表驱动），整机全长 700 mm，分头 / 体 / 尾三段，壁厚 3.2 mm。

> ⚠️ **脚本产出的网格不是单一水密实体**，是多部件叠加。直接 3D 打印前需先在 CAD / 切片软件中做**布尔合并**，否则切片会异常。

**制造级工作必须在 CAD 中完成**：止口、密封槽、螺钉孔、装配间隙。脚本产物的定位是**外观与装配参考**，不作为最终加工依据。内部电气（电池盒、控制器）未建模，无需照搬。

### 3.3 唧筒（沉浮机构）

```text
N20 直流减速电机
    │
    └─► 马达齿轮 ──► 大齿轮（减速）──► 螺杆 ──► 活塞
                                          │
                            100 ml 注射器筒体 ──► 排水体积变化
                                          │
                          微动开关 ×2 ◄────┴──── 行程两端限位
```

装配要点：

- **螺杆自锁**是断电保位的关键，装配后手动推拉活塞应感到明显阻力、松手不回退。
- **两个微动开关**装在行程两端，防止螺杆顶死导致电机堵转。
- ⚠️ **限位开关接线尚未纳入当前固件**，需在整机联调时补充（见 [电控编写.md](电控编写.md) 扩展章节）。
- ⚠️ 活塞在筒体内的**动密封是全机防水的关键风险点**，必须实测确认。

## 四、上电前检查清单

**逐项打勾，不要跳。**

- [ ] 用万用表确认 XT60 极性正确（**保险丝不防反接**）
- [ ] 5 A 保险丝已装好，**未被导线短接**
- [ ] 断开负载，单独测 LM2596S 输出，调到电机/舵机额定电压
- [ ] 测 ME6211 输出为 **3.3 V**（输入低于约 3.5 V 会跌出稳压区）
- [ ] 两轨地线共地，且地回流路径足够宽
- [ ] JY901S 的 `PB6/PB7` **已焊 4.7 kΩ 上拉**
- [ ] ESP-01S `PA2/PA3` 交叉收发正确
- [ ] TB6612 `STBY` 已接 3.3 V 高电平（低电平会让两桥输出高阻）
- [ ] 电机端未直接接 GPIO
- [ ] `CFG_DEBUG_BUTTONS_ENABLED` 确认为 **0**（见下方警告）

## 五、首次上电

### 5.1 上电顺序

1. **先不接电机与舵机**，只上逻辑部分，确认 3.3 V 轨正常、PC13 指示灯按 500 ms 翻转。
2. **接 Type-C 到电脑**，在串口助手中应能看到周期性输出。看不到就停下排查，不要继续。
3. **再接 SWD**，确认 ST-Link 能识别芯片。此时双通道应可同时工作。
4. **最后接动力轨负载**（TB6612 VM、舵机），逐路确认。

### 5.2 判断「MCU 是否在跑」

最快的方法：**看串口有没有输出**。有输出说明固件在运行、时钟配置正确；无输出则优先怀疑供电、时钟或烧录未成功。

## 六、常见问题

| 现象 | 排查方向 |
| --- | --- |
| 全板无电、串口无输出 | **先查保险丝是否熔断**（不可逆，需更换）；再查 XT60 是否插到位 |
| 上电即烧毁模组 | **极大概率是 XT60 极性接反**，用万用表确认 |
| 逻辑轨不是 3.3 V | 查 ME6211 输入是否正常、输出电容是否虚焊 |
| 动力轨电压不对 / 电机无力 | 调 LM2596S 电位器；确认未低于最小工作压差、未触发限流 |
| 电机一转 IMU/OLED 就复位 | **两轨未隔离干净**，检查共用细走线或地回流路径过窄 |
| 电机不转但接线无异常 | **优先查 TB6612 的 STBY**，低电平会让两桥输出全部高阻 |
| 有 12 V、STBY 已拉高却带不动 | **占空比是否为 100%？** 见本文开头「三个坑」第 1 条 |
| 屏能显示但 IMU 读不到 | **`PB6/PB7` 缺 4.7 kΩ 外部上拉**（`IMU … pu=11` 即为该判据） |
| 烧录报 `failed to erase memory` | 先用「写 RAM」做对照实验排除 MCU 内部 flash 故障 |

## 七、安全须知

> 🔴 **下水前必须确认**：
>
> 1. **`CFG_DEBUG_BUTTONS_ENABLED` 已设回 `0`。** 该调试功能有意放开了「无链路即无运动」的看门狗保证 —— K1 启动的转动在**完全没有上位机时会一直持续**。
> 2. 两路电机与舵机已装好机械保护，可立即断电。
> 3. 已完成台架启停、失联、ESP 复位与供电恢复测试。
> 4. 95% / 60% 均为**开环电压设定，不是限流或过流保护**。TB6612 **无过流/短路保护规格**，堵转电流必须实测。
> 5. 唧筒活塞的动密封已实测确认。
