# 鱼尾装配 · 结构件开源

本目录是仿生鱼**尾段结构**的可发布零件集，供复刻者参考装配与打印。所有零件均为自主设计，经多轮迭代收敛到当前版本。

单位 **mm**。SolidWorks 原生件为 `SLDPRT` / `SLDASM`，通用交换格式为 `step`。

## 传动与推进方案说明

尾段采用**曲柄摇杆式**传动，由 **370 直流减速电机**驱动。

> ⚠️ **已废弃方案**：早期设计使用「42 两相双极步进电机 + 软件四拍换相」驱动尾段，后因失步不可观测、TB6612 驱动余量偏紧等问题，改为直流减速电机方案。相关步进零件（`42HS34-FS.STEP`、`步进支架.step`）**未包含在本目录中**，请勿据此推断当前硬件参数。

## 迭代说明

尾部支撑是尾段设计中迭代最多的零件，经 V2 → V3R → V4R → **V6F / V4F** 多轮收敛。演进过程中反复权衡了传动力臂、支撑刚度与 3D 打印方向：早期版本偏重外形贴合，后期版本为保证电机负载下的结构刚性而增加加强筋与壁厚。

## 打印与装配提示

- 支撑件为主要承力件，建议使用 **PETG**，壁厚不低于 3.2 mm，填充率 40% 以上。
- 装配前请核对本目录版本号与自身硬件方案是否一致，**避免混用历史版本**。
- 关节与快拆件建议先试打印单件确认配合间隙，再批量打印。
- 部分零件的装配间隙与止口需根据实际打印精度微调。
