## 一、设计取向

拓展板的设计目标只有一句话：**任何一路模块出问题，都应该是拔下来换掉，而不是拿烙铁上去查。**

| 原则 | 做法 |
| --- | --- |
| 模组化 | TB6612、ESP-01S、JY901S、OLED 均经排针/排母连接，可逐个替换 |
| 可拔换核心 | STM32 核心板以 **32 针母座**插接，可整体取下单独烧录或替换 |
| 全扇出 | UART 与电机、舵机接口**全部引出排针**，杜邦线即可外接新模组 |
| 可观测 | 全链路信号留可测量的测试点；SWD 与串口双通道并行 |
| 可保护 | 输入端 5 A 一次性保险丝兜底短路 |

这套取向沿用 **TI 杯电子设计竞赛**的工程范式：主控 + 功能模组的积木式组合，每个模组独立供电、独立接口、可单独测试。

## 二、模块接线总表

| 模块 | 模块接口 | STM32 引脚 | 用途/说明 |
| --- | --- | --- | --- |
| 运行指示灯 | LED | `PC13` | GPIO 输出 |
| TB6612 电机驱动器 | `PWMA`、`PWMB`、`AIN1/AIN2`、`BIN1/BIN2` | `PA0`、`PA1`、`PB12`、`PB13`、`PB14`、`PB15` | `PA0/PA1` 为两路 PWM；`PB12~PB15` 为两路方向控制 |
| 电机端口 1 | `M1+`、`M1-` | 驱动器输出 | 接 370 推进电机 |
| 电机端口 2 | `M2+`、`M2-` | 驱动器输出 | 接 N20 唧筒电机（12 V 版） |
| 舵机 1 | `SIG` | `PA6` | TIM3_CH1 PWM 输出 |
| 舵机 2 | `SIG` | `PA7` | PWM 输出（当前固件未启用） |
| OLED 模块 | `GND`、`VCC`、`SCL`、`SDA` | `GND`、`+3.3V`、`PB8`、`PB9` | 四线接口；软件 I²C |
| ESP-01S 模块 | `GND`、`VCC`、`RXD`、`TXD` | `GND`、`+3.3V`、`PA2`、`PA3` | `RXD`→`PA2`，`TXD`→`PA3`；`RST/EN/IO0/IO2` 悬空 |
| JY901S 陀螺仪 | `SCL`、`SDA` | `PB6`、`PB7` | 软件 I²C，**需外接 4.7 kΩ 上拉** |
| USART1 接口 | RX、TX | `PA9`、`PA10` | 预留串口 |
| USART3 / CH340 | TX、RX | `PB10`、`PB11` | 板载 CH340 转 Type-C，调试日志输出 |
| 按键 1/2/3 | 开关输出 | `PB0`、`PB1`、`PA8` | 低电平有效输入，内部上拉 |
| 下载调试接口 | SWDIO、SWCLK | `PA13`、`PA14` | SWD |
| 外部晶振 | OSC_IN、OSC_OUT | `PD0`、`PD1` | HSE 8 MHz |

### 各模块接线要点

**TB6612**：逻辑电源接 `+3.3V`，电机功率电源接动力轨，逻辑地与功率地均接 `GND`。信号为 `PWMA→PA0`、`PWMB→PA1`、`AIN1→PB12`、`AIN2→PB13`、`BIN1→PB14`、`BIN2→PB15`。两路电机输出接 `M1±` / `M2±`；**电机端不得直接接 STM32 GPIO**。

**JY901S**：`VCC` 接 3.3 V，`SCL`/`SDA` 接 `PB6`/`PB7`。模块的 `RX`/`TX` 未接入 STM32，`D0~D3` 也不是通信引脚。

**OLED**：按 `GND→GND`、`VCC→+3.3V`、`SCL→PB8`、`SDA→PB9` 连接。

**ESP-01S**：`GND→GND`、`VCC→+3.3V`、`RXD→PA2`、`TXD→PA3`，构成 USART2 交叉收发。`RST`、`EN`、`IO0`、`IO2` 在原理图中均未连接，不应误接。

## 三、双通道调试：SWD + 板载 CH340

板载 **CH340** 转出 **Type-C 母座**，与 SWD 构成两条**物理独立、互不抢占**的调试通道，可同时接在同一台主机上。

```text
┌───────────────┐   SWD（烧录 / 断点 / 寄存器）  ┌────────────────┐
│   ST-Link     │◄──────────────────────────────►│                │
└───────────────┘                                │  STM32F103C8T6 │
┌───────────────┐   USART3（日志 / V1 状态帧）    │   拓展板        │
│ CH340 (Type-C)│◄──────────────────────────────►│                │
└───────┬───────┘                                └────────────────┘
        │ 两条独立 USB 通道同时挂在同一台主机
┌───────▼────────────────────────────────────────┐
│  AI Agent（可读串口日志 + 可下载固件 + 可复位）   │
└────────────────────────────────────────────────┘
```

**为什么这很重要**：调试的本质是「**改代码 → 烧录 → 看现象 → 再改**」的循环。

- **能烧**：SWD 让工具/Agent 可直接下载固件、复位、halt 查看寄存器，无需人工点 IDE；
- **能看**：CH340 把 `ESP server=… tcp=… reset=… error=…`、`IMU scl= sda= st= probe=`、`STA` 状态帧以**纯文本**吐到串口，工具/Agent 无需摄像头或人工转述即可读到设备真实状态；
- **可交叉验证**：SWD 侧异常时，串口侧仍在独立输出，能立刻区分「固件没跑起来」还是「调试器/接线问题」。

**Type-C 直连的实际收益**：一根普通手机线即可接电脑看串口，不必再找 USB-TTL 转接板，也不必临时接线。这显著降低了「临时想看一下日志」的操作成本。

> 📌 协议选择**可打印 ASCII + 换行分帧**（见 `通信协议.md`）正是为此配合：串口日志可被工具直接解析，而非面对需要额外解码的二进制流。

## 四、电源分配

| 模块类别 | 电源轨 | 电压 |
| --- | --- | --- |
| STM32、OLED、ESP-01S、JY901S、CH340 | 3.3 V 逻辑轨（ME6211） | 3.3 V |
| TB6612 逻辑 | 3.3 V 逻辑轨 | 3.3 V |
| TB6612 VM、舵机 | 动力轨（LM2596S） | 按电机/舵机额定值 |

**所有模块必须共地**；电机、舵机功率电源不得由 STM32 GPIO 直接提供。若出现「电机一动、IMU/OLED 就异常复位」，首先怀疑逻辑轨被动力轨的电流冲击污染（共用细走线或地回流路径过窄）。

详见 [`电源方案与电压汇总.md`](电源方案与电压汇总.md)。
