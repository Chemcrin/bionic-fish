# 仿生鱼完整项目交付说明

## 交付内容

- `Android上位机/`：Kotlin + Jetpack Compose 控制端完整源码、Gradle wrapper、调试 APK、测试 APK、模拟器测试报告、三套真实渲染截图及 Android 侧文档。
- `STM32控制工程/`：STM32F103C8T6 HAL/CubeMX 风格源码、CubeMX 配置、协议测试及固件侧文档。
- `原始资料/STM32拓展板_2026-08-26_引脚分配.md`：用户提供的引脚分配资料原件，仅作为输入依据保存；其中的历史需求不覆盖本交付采用的最终决定。

## 最终硬件与协议口径

1. 保留一颗 42 型两相双极步进电机。
2. TB6612 的 A、B 两个 H 桥分别连接该步进电机的线圈 A、线圈 B；不存在虚构的 STEP/DIR 引脚。
3. N20 减速电机控制已经从 STM32 运行时代码、Android UI、控制帧和状态帧中移除。旧文档/负向测试中出现 `n20_*` 仅用于说明兼容处理，不表示仍支持 N20。
4. ESP-01S 只按 Wi-Fi 模块处理。Android 已实现 TCP、UDP 和 Mock 传输；Bluetooth Classic/BLE 仅保留不可用的扩展接口，不会把 ESP-01S 显示为蓝牙设备。
5. 真实 ESP 工作模式、固件版本、TCP/UDP 选择、IP、端口、服务发现和配网流程均为“待确认”，不得把 Mock 测试结果当作硬件联调结果。

## 上电前必须确认

- 断电测出步进电机两组独立线圈，并确认 M1 只接线圈 A、M2 只接线圈 B；原 N20 必须从 M2 物理断开。
- 确认 TB6612 `STBY`、VM/VCC、线圈额定电流/电压、步距角、减速比、每输出转换相数、相序和安全 PWM。
- 固件默认保持步进参数安全门禁，未确认上述参数时不会励磁驱动步进电机。
- 确认 JY61P I²C 地址/寄存器/电平，以及所有外部输入不超过 STM32 可接受的 3.3 V。
- 先完成无负载受控台架测试，再进行水中测试；无线安全停止不能替代 STM32 失联停机和硬件急停措施。
