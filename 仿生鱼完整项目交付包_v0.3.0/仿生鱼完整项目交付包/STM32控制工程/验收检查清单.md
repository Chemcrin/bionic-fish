# 验收检查清单

## 使用方式

本清单区分“源码已有对应实现”“能完成交叉编译”和“在真实硬件上安全可靠运行”。没有编译日志、示波器/万用表数据或样机测试记录的项目只能标为“待验证”。

- 已覆盖：源文件与文档已有明确实现/边界，仍需构建或实测。
- 待验证：需要主机、目标板或台架证据。
- 阻断/待确认：缺少关键硬件信息，解除门禁或接电会带来功能/安全风险。

## 6. 放行条件

以下条件同时满足前，工程只能作为受控台架软件，不能用于水中或无人值守运行：

1. 完成 B3、B4、B7、B8：两线圈正确接到两桥、原 N20 已物理断开、电平安全、`STBY` 与硬件失效保护明确。
2. 完成 C2~C5：线圈对/相序、步距角、换相数、减速比、额定电流/电压和安全 PWM 均有实测记录，并谨慎解除参数门禁。
3. 完成 C6、C8、C9：60/100 档、失联/溢出停机与舵机回中均经实物验证；实际速度没有传感器时保持 `NA`。
4. 完成 D1~D6、E1~E7：显示、姿态、电平、通信、协议错误和故障位的行为可重复验证。
5. 保存目标板交叉编译日志、map 文件、台架波形/电流/温升记录和最终配置版本，形成可追溯的验收证据。
