## 本轮已验证的 UI 风险点

- 固定安全停止栏在控制内容滚动到末尾后仍可见；
- 320×480 dp 容器、200% 字体和长错误提示并存时，安全停止仍可见、可点击且高度至少 44 dp；
- 不支持反向时不暴露可执行“后退”按钮，并显示固件能力说明；
- 舵机滑杆拖动期间不发送，松手只提交一次最终目标；
- 浅色、深色和 200% 字体模式均完成真实渲染输出。
