# 仿生鱼工程

本项目制作一只用于教学与水下任务演示的仿生鱼。当前软件交付采用 **STM32F103C8T6 主控 + ESP-01S Wi-Fi 通信 + Android TCP 上位机**。HarmonyOS / ESP32 WebSocket 方案暂停，历史资料不覆盖本页的当前接口和范围。

## 当前系统

```text
Android 控制器
  │ Wi-Fi：BionicFish-AP，TCP 192.168.4.1:9000
ESP-01S：兼容的 ESP8266 AT 固件
  │ UART0 ↔ USART2，115200 / 8N1，无流控
STM32F103C8T6
  ├─ TB6612 A/B 双 H 桥 → 一颗两相双极步进电机
  ├─ TIM3 CH1 → 一路舵机
  ├─ 软件 I²C PB6/PB7 → JY61P 姿态
  ├─ 软件 I²C PB8/PB9 → SSD1306 128×64 状态屏
  └─ USART3 → CH340N 调试/状态输出
```

- 控制协议为 V1 ASCII，包含完整 CMD、同序号 ACK/ERR 和周期 STA。Android 通过安全停止 CMD 的 ACK + STA 确认控制链路；加入 Wi-Fi 或连上 TCP 本身不等于握手完成。
- 推进电机按开/停控制：前进时固定 10% PWM、每 50 ms 换相一次，停止或失联时释放两组线圈。不做位置或 RPM 控制；舵机范围为相对中位 ±30°。
- TB6612 两桥都用于步进线圈，当前没有 N20 功能，也没有原方案的三舵机、深度闭环或自主导航实现。
- 按键本轮保留未使用；屏幕保留原单页布局，显示推进运行状态、舵机命令、有效姿态、控制保活和故障。无效姿态显示 `---`，网络 STA 显示 `NA`。当前是自写状态屏，并未移植上游 Astra。

## 构建和首次使用

在 `STM32控制工程` 中：

```powershell
python scripts/build.py firmware --bootstrap
python scripts/build.py host --bootstrap --host-cc C:/path/to/native-gcc.exe
```

构建只产生文件，不会自动烧录或驱动电机。默认产物在 `build-firmware/`，包括 BIN、ELF、MAP 和记录版本/哈希的 `build-info.json`。当前固定 CubeF1 v1.8.6；不要在源码目录直接用 CubeMX 重新生成，按构建说明在独立目录生成后合并。

1. 确认实际 ESP-01S 使用受支持的 AT 固件、正确 UART 引脚、115200-8-N-1 和足够的 3.3V 供电。自定义 TCP/UDP 透明桥与当前 STM32 不兼容。
2. 编译并烧录 STM32；通过 USART3 观察 ESP 初始化诊断和 STA。手机加入 `BionicFish-AP`（默认密码 `12345678`），打开 Android 设备页“AP 直连”，保持该无互联网 Wi-Fi。
3. 先验证 STOP 的 ACK、STA、舵机与姿态，再点击前进做固定低速连续转动测试。默认允许前进，不再要求先填写步距角、减速比或参数确认标志。
4. 电机两组线圈已确认分别接入 TB6612 M1/M2；VM 来自 45C、3S 航模锂电池，报告 VM=12 V、线圈约 3 Ω。当前 10% PWM 是低功率试运行初值，不是恒流保护或已测额定参数；实际转动和温升在试机时核对。
5. 完成台架启停、失联、ESP 复位和供电恢复测试，再进行水中试验。

## 当前验收状态

本轮固定低速版本已通过 **17/17 CTest** 和真实 Arm 交叉构建，BIN为 **24,604字节**。Android 0.3.2/code5通过 **56/56单元测试、23/23 MuMu设备测试**，lint 0错误，APK已安装并启动。固件哈希见 `build-firmware/build-info.json`，Android产物和证据见[验证记录](仿生鱼完整项目交付包_v0.3.1/仿生鱼完整项目交付包/仿生鱼安卓AP直连_v0.3.0_2026-09-06/Android工程/验证结果_2026-09-09.md)。未发布新Release。

用户已提供 AT 1.7.4.0 回包，与当前驱动版本分支相符；RTS 流控修正后的查询为 `+UART_CUR:115273,8,1,0,0`，当前串口配置已匹配。无铭牌 42 步进电机的两组线圈已用万用表确认并分别接入 TB6612 M1/M2，VM=12 V、线圈约 3 Ω；本轮按固定低功率试运行，实际效果待上板观察。详见[硬件记录](仿生鱼完整项目交付包_v0.3.1/仿生鱼完整项目交付包/STM32控制工程/硬件引脚与驱动说明.md)。

当前尚未完成实板验收；需验证实际低速转动、STM32/ESP/Android TCP 链路、姿态和屏幕显示。软件测试通过不等于整机已完成下水试验。
