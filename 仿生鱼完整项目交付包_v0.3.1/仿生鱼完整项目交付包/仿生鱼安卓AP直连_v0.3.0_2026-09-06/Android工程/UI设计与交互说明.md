# UI 设计与交互说明

## 1. 设计依据与范围

本说明依据用户本轮列出的 UI 规则整理。交付资料中未找到 `UI设计RP.md`，因此不存在对该文件的逐页提炼或视觉复刻；若后续取得原文件，应补做设计令牌、页面结构和文案差异审查。

本应用面向水面设备控制，首要目标是让用户随时看见连接状态和停止入口。UI 不提供已从 STM32 固件移除的 N20 功能，也不把 ESP-01S 描述为蓝牙设备。

## 2. 信息架构

当前实现采用单 Activity + Navigation，包含以下主目的地：

1. **设备**：首卡为无需扫描的 AP 直连入口；其后保留 Mock/普通 TCP/UDP、扫描或手工配置、连接状态。AP 预置不虚构 RSSI 或发现时间。
2. **控制**：顶部显示连接与目标摘要，根布局底部固定醒目的安全停止栏；提供前进、反向能力说明、左/右/直行、60/100 RPM 与舵机安全角度控制。
3. **状态/调试**：显示步进目标/估算/实际有效性、舵机、姿态、链路、RTT、更新时间、故障位和通信日志。
4. **设置**：独立 AP 热点名称/IPv4/端口、普通 LAN/UDP 参数、控制方式、安全停止、超时、主题、日志导出和仅在能力可用时出现的蓝牙设置。

控制页不应要求进入二级页面才能停止。导航离开控制页时按配置触发安全停止，并通过提示条报告成功或失败。

## 3. 设计令牌

令牌通过 Material 3 `ColorScheme`、`Typography`、`Shapes` 和统一间距对象实现，业务组件不得散落硬编码颜色和字号。

### 3.1 间距与尺寸

| 令牌 | 值/用途 |
| --- | --- |
| `space-1/2/3/4/6/8` | 4/8/12/16/24/32 dp |
| 最小触控目标 | 44×44 dp；优先采用 Material 48 dp 默认值 |
| 页面水平边距 | 紧凑屏 16 dp，宽屏可增加但不拉长单行正文 |
| 卡片/分组间距 | 12~16 dp，语义分组优先于装饰分隔 |
| 圆角 | 使用主题 small/medium/large，危险按钮不靠形状单独表达 |

### 3.2 颜色语义

- `primary`：主要连接/确认动作。
- `secondary`：次要切换与选中状态。
- `success`：连接成功、命令确认；同时显示文字/图标。
- `warning`：数据即将过期、门禁、权限受限。
- `error`：失联、协议错误、停止发送失败和活动故障。
- `info`：Mock、扫描、重连及一般提示。

浅色和深色主题分别验证。普通文本对比度至少 4.5:1，大文本至少 3:1；连接/故障不能只用红绿颜色区分。

### 3.3 字体

采用系统可缩放的 `sp` 与 Material 文本样式，不固定像素高度。正文、标签、数值和标题保持清晰层级；状态数值带单位，`NA`、过期和故障说明使用可读文本。必须在系统字体 200% 下验证换行、滚动和按钮可达性。

## 4. 可复用组件

| 组件 | 必须状态/行为 |
| --- | --- |
| `ConnectionBadge` | 未连接、扫描中、连接中、握手中、已连接、失联、重连中；图标+文字。 |
| `DeviceListItem` | 名称、传输、IP/地址、RSSI（若来源可用）、发现时间、选中和连接进度。 |
| `DirectionPad` | 前进/反向/停止、左/右/直行；按下、释放、禁用、焦点与 TalkBack 描述。 |
| `EmergencyStopButton` | 高视觉优先级；立即清空运动意图并排队安全停止；不依赖二次弹窗阻挡急停。 |
| `SpeedSelector` | 60 RPM/100 RPM，仅允许两个协议值。 |
| `ServoControl` | -30°~+30° 限幅；快捷 -30/0/+30 和可访问的当前值描述。 |
| `TelemetryCard` | 数值、单位、有效/NA/过期、采样时间；估算值和真实值明确区分。 |
| `FaultBanner` | 故障位、简明原因、建议动作和进入详情；不可仅显示十进制码。 |
| `InlineMessage` | success/warning/error/info，支持必要时重试或打开设置。 |
| `Loading/EmptyState` | 可取消扫描、重试、手工输入或进入 Mock，不使用无意义大插画。 |
| `ConfirmDialog` | 用于断开、清除配置等可逆性较差的操作；急停本身不要求确认。 |

## 5. 关键交互

### 5.1 发现和连接

1. AP 直连使用首卡“打开系统 Wi-Fi 设置”手工加入热点，返回点“连接仿生鱼热点”，无需扫描；普通 LAN/Mock 则主动选择对应传输，再开始扫描/输入地址。
2. 扫描页持续显示可取消动作；发现时间和 RSSI 无真实来源时显示“不可用”，不得制造数值。
3. 点击设备后显示连接阶段及超时原因。
4. 传输连接成功后先执行 V1 安全停止握手；ACK 与 STA 都有效后才显示“已连接”。
5. 首次成功设备可保存为“用户选择的设备”，下次可提示重连，但不静默连接陌生设备。
6. 重连后保持停止状态，不恢复断线前的前进/转向输入。
7. 活动连接期间禁用再次扫描、切换传输和直接改连其他设备；用户须先使用带确认说明的“安全断开”。领域层仍会二次门禁，不能靠 UI 单独保证安全。

Bluetooth 入口由手机能力、应用功能开关和实际鱼端蓝牙配置共同决定。仅检测到手机蓝牙并不足以把 ESP-01S 当成蓝牙设备。

### 5.1.1 AP 直连首卡与独立配置

- “设备”页第一张业务卡片显示“AP 直连 · 仿生鱼热点”、配置 SSID、`TCP IP:端口 · 无需扫描`，以及系统 Wi-Fi 设置和连接按钮。卡片不依赖扫描结果存在，因此首次安装即可找到入口。
- 提示初始密码来自用户指引，修改后以实际配置为准；明确说明“热点无互联网属正常”“保留连接”“应用不会自动确认热点名称”。不得显示“已验证 BionicFish-AP”等没有 SSID 数据依据的状态。
- 按钮沿用主题颜色、图标+文字与最小触控目标；纵向排列以适应窄屏和 200% 字体，不用强制单行裁切热点名、地址或错误原因。
- 扫描中、连接中、重连中或已有活动会话时，禁止直接切换 AP 或跳系统 Wi-Fi 设置；用户先取消扫描/安全断开。失联后的手动 AP 重试经过同一会话清理和安全路径。
- AP 连接成功后显示“AP 直连 · TCP”与 V1 握手状态，卡片提供“进入控制页”按钮；不自动发送运动命令，也不改动控制页原有停止优先级。
- “设置”页 AP 配置组与普通 LAN 主机/端口分开，支持 SSID、IPv4、端口编辑并通过现有保存动作提交。连接用保存值，未保存草稿不能悄悄改变目标。
- AP SSID 只是加入热点的提示名，不做自动读取/验证；Wi-Fi 本地子网匹配只保证选择合适网络，不等于设备身份认证。失败信息区分未找到合适 Wi-Fi、TCP 服务不可达、握手 ACK/STA 缺失和热点失联。
- 保存的 AP 端点不静默自动连接；会话内自动重连保留 Wi-Fi 专用路由，每次以停止状态重新握手。普通局域网参数不被 AP 预置覆盖。

### 5.2 控制

- 安全停止栏由根 `Scaffold.bottomBar` 承载，手机端位于底部导航上方；它不随控制内容滚动，也不会被长提示条或字体放大挤出视口。TalkBack 描述会随空闲/等待 ACK 状态动态说明当前动作。
- “松手即停”模式中，按住前进才持续发送前进；抬手、手势取消、窗口失焦或页面离开立即提交停止。
- “显式停止”模式中，运动状态保持到用户点击停止或安全事件发生；模式名称和风险说明必须可见。
- TalkBack 触摸探索不提供可靠的指针按下/释放生命周期；检测到该模式时应用自动切换到可访问的“显式停止”，方向按钮用标准点击操作，醒目停止按钮保持首屏可达。
- 默认固件不允许反向。反向按钮应依据能力状态禁用或允许点击后展示固件返回的明确原因，不能假装动作成功。
- 左转发送负舵机角，右转发送正角，直行强制为 0；按钮状态与最终发送的 `turn/servo` 一致。
- 左/中/右和 60/100 RPM 预设使用边框、勾选和状态语义表达选中；舵机滑杆拖动时只更新本地预览，松手才提交一次最终目标。
- 60/100 RPM 是目标档位，不用动画速度暗示真实机械转速。
- 不显示 N20 卡片、滑杆、方向按钮或占位状态。

### 5.3 停止、断开和后台

- 急停是立即动作，不先弹确认框；执行结果通过提示条和日志反馈。
- “停止行进”、松手停止、模式切换和急停共用最高优先级安全通道；旧运动队列在本地停止意图建立时即被截断。
- 用户主动断开可显示确认，确认文案说明将先尝试发送安全停止。
- 离开控制页或应用进入后台时，根据设置执行一次高优先级安全停止。若网络已经不可写，应显示“停止帧未送达，等待固件失联保护”，不能显示成功。
- 应用恢复前台或重连后，控制状态从停止开始。后台停止通过仓库的安全停止代次同步到 ViewModel，不能让旧 `FORWARD` 在修改舵角/速度时复活。
- “后台/退出控制页停止”和“安全停止时舵机回中”开关以仓库持久化值为唯一有效来源；保存成功后才改变 UI，避免未保存草稿与实际动作分裂。

### 5.4 状态与调试

- `step_rpm` 标“目标”，`step_est` 标“节拍估算”，`step_actual=NA` 标“无测速反馈”。三者不得合并为一个“实际转速”。
- 姿态角分别带 `°`；收到 `NA` 或超时后显示无效/过期，而不是 0°。
- 显示协议 RTT、最后收到时间和状态新鲜度。过期卡片保留最后值仅用于参考时，必须覆盖清晰的“数据过期”标记。
- 故障位逐项翻译；bit6 显示“保留位”，未知高位保留十六进制值。
- 日志列表区分 TX/RX、传输层和协议结果；导出必须由用户主动触发。

## 6. 响应式布局

- **320~599 dp 紧凑宽度**：单列、纵向滚动；连接摘要在内容顶部，安全停止栏固定在底部导航上方，方向控制不与速度/舵机重叠。
- **600 dp 及以上**：可用双栏；左侧主要控制、右侧实时状态。页面仍保留逻辑阅读顺序，不能只为横屏绝对定位。
- **横屏低高度**：停止入口由根底栏固定可达，其余内容滚动；系统栏、显示切口和手势区使用安全内边距。
- 文本增大到 200% 时允许卡片增高和按钮文字换行；禁止截断关键错误或将触控目标缩小。
- 键盘、旋转、进程重建后恢复设置和已选设备，但不恢复运动状态。

## 7. 无障碍

- 所有图标按钮具有可本地化的 content description；方向组合报告动作、选中和禁用原因。
- 状态变化使用适度 live region/语义通告，避免每个 200 ms 遥测帧都打断 TalkBack。
- 滑杆提供增加/减少动作和“当前角度 X 度”；不能要求精确拖动才能回中。
- 焦点顺序为连接状态→停止→运动/转向→速度→舵机→详情。
- 颜色之外使用文字、形状或图标表达成功/警告/错误；支持外接键盘/D-pad 基础焦点操作。
- 错误信息说明发生了什么以及下一步（重试、检查网络、打开权限设置、进入 Mock）。

## 8. 动效与系统偏好

动画只用于扫描、连接、刷新和状态变化反馈，不能阻塞输入或推迟停止命令。当前实现统一关闭 NavHost 页面过渡；开启应用内“减少动态效果”后，扫描、连接和停止的旋转进度改为静态图标+文字。系统关闭动画时仍保留完整文字状态，不依赖动效表达结果。

## 9. 文案与术语

- 使用“AP 直连 · TCP”“Wi-Fi TCP/UDP”“Mock”，不使用“ESP 蓝牙”。
- 使用“目标 RPM”“估算 RPM”“无测速反馈”，不把命令值叫实际值。
- 使用“失联”“数据过期”“停止帧未送达”，不使用模糊的“好像离线”。
- AP 地址/端口/初始热点名标注为用户指引给出的预置且支持修改；普通 LAN/UDP、UUID 等未提供参数仍标“待确认”，不用虚构示例冒充默认配置。

## 10. UI 验证结果与边界

以下为历史 v0.2.0 控制页验证记录，不能冒充 v0.3.0 本次结果：

- 13 个 Compose instrumentation 测试已在 Android 15 / API 35 AOSP ATD 模拟器 `BionicFishApi35` 上执行通过，0 失败、0 错误、0 跳过。
- 自动场景覆盖醒目停止、滚动到末尾后停止栏仍可见、320×480 dp 容器/200% 字体/长错误提示下停止仍可点击、反向能力门禁、蓝牙隐藏、过期/NA 遥测、离页停止、四主视图导航，以及舵机滑杆一次性提交。
- 已用真实 Android Compose 渲染管线输出 [浅色](artifacts/screenshots/control-screen-light.png)、[深色](artifacts/screenshots/control-screen-dark.png) 和 [200% 字体](artifacts/screenshots/control-screen-200-percent-text.png) 三张 1080×2280 截图；这些图片不是设计稿或 Preview。
- 目标真机的 TalkBack 完整焦点顺序、系统“减少动态效果”、平板及更多横竖屏尺寸、真实锁屏/后台切换仍需人工验收；模拟器通过不替代 ESP/STM32 和机械联调。
