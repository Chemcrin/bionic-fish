# 固定低速 TCP 控制版：先看这里

当前源码版本为 **Android 0.3.2 / versionCode 5**，配合上一级 STM32控制工程 的本轮固件。目录名中的 v0.3.0 是历史归档名称。

## 安装

安装本轮构建的 [app-debug.apk](Android工程/app/build/outputs/apk/debug/app-debug.apk)。大小、SHA-256 和本轮测试结果见[验证记录](Android工程/验证结果_2026-09-09.md)。同级旧 v0.3.0 APK、原构建记录与界面预览保留为历史资料；AndroidTest APK不是控制器。

## 使用

1. 手机加入 BionicFish-AP，默认密码12345678，保持无互联网Wi-Fi连接。
2. 在设备页使用 AP直连，连接TCP 192.168.4.1:9000。
3. 安全STOP收到同序号ACK和有效STA后进入控制页。
4. 点前进后推进电机以10%PWM、50ms换相周期持续低速转动；点停止或失联后释放两相。舵机仍可调节，不再选择或校准RPM。

状态中的运行/停止表示驱动命令，真实转速未测量；OLED保持原单页布局。请将新版APK与本轮固件配套使用：旧0.3.1 APK不支持RPM为NA的新状态帧。

当前系统采用ESP-01S AT/TCP，UDP入口已禁用，HarmonyOS和历史透明桥暂停。MuMu验证覆盖软件；真实ESP、UART、电机和传感器仍需实板联调。

完整构建步骤见[Android README](Android工程/README.md)和[STM32 README](../STM32控制工程/README.md)。
