# 仿生鱼 AP 直连版 v0.3.0

本文件夹中安装手机的文件只有一个：`仿生鱼控制器_v0.3.0_AP直连.apk`。这是可安装的开发调试签名APK，支持Android8.0及以上，不是AndroidTest测试包。

## 连接步骤

1. 手机安装新版APK。与此前同签名版本可直接覆盖升级；若手机提示签名不一致，先导出旧日志/记录设置，再由用户决定是否卸载旧版。
2. 打开“设备”页，点“打开系统 Wi-Fi 设置”，手工加入 `BionicFish-AP`，初始密码 `12345678`；密码修改后以设备实际配置为准。
3. 遇到“无互联网”选择保留该连接，然后返回APK。
4. 点击“连接仿生鱼热点”，默认TCP `192.168.4.1:9000`，不需要扫描。不同参数可到“设置 → AP直连参数”修改并保存。
5. 握手成功后进入控制页，先测试停止与舵机回中，再测试±30°与60/100RPM。

保留42步进驱动控制，未恢复N20。原TCP/UDP/模拟器模式仍在；AP专用Socket仅走匹配子网的Wi-Fi，不自动切到移动数据。
