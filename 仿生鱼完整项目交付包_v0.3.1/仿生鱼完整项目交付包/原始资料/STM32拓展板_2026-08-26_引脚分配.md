## 模块接线方式

### TB6612

TB6612 的逻辑电源接 `+3.3V`、电机功率电源接原理图的 `+5V`，逻辑地和功率地均接 `GND`。具体信号为：`PWMA -> PA0`、`PWMB -> PA1`、`AIN1 -> PB12`、`AIN2 -> PB13`、`BIN1 -> PB14`、`BIN2 -> PB15`。两路电机输出分别接 `M1+ / M1-` 和 `M2+ / M2-`；电机端不得直接接 STM32 GPIO。

### JY61P 陀螺仪

JY61P 的 `VCC1` 接 `+5V`，`GND1` 接 `GND`；`SCL`、`SDA` 分别接 STM32 `PB6`、`PB7`（原理图网络标注为 `uart2`）。模块 `RX`、`TX` 接到独立的两针接口 `U3`，没有接入 STM32 引脚；`D0~D3` 也不是 STM32 通信引脚。

### OLED 屏幕

OLED 四线接口按 `GND -> GND`、`VCC -> +3.3V`、`SCL -> PB8`、`SDA -> PB9` 连接。

### ESP-01S

ESP-01S 按 `GND -> GND`、`VCC -> +3.3V`、`RXD -> PA2`、`TXD -> PA3` 连接，构成 USART2 交叉收发。`RST`、`EN`、`IO0`、`IO2` 在原理图中均未连接，不应误接到 STM32。

## 未连接 STM32 的网络

JY61P 的 `RX/TX` 仅连接到两针外部接口 `U3`，未连接 STM32；其 `SCL/SDA` 实际连接为 `PB6/PB7`，不属于未连接网络。

## 电源与共地

| 模块类别 | 电源 | 地 |
| --- | --- | --- |
| STM32、OLED、ESP-01S、逻辑接口 | `+3.3V`（以原理图标注为准） | `GND` |
| 舵机及电机驱动器 | `+5V` / `+12V` | `GND` |

所有模块必须共地；电机、舵机功率电源不得由 STM32 GPIO 直接提供。
