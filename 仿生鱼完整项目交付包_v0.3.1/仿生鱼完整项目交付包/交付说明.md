# 仿生鱼当前交付说明

2026-09-09 工作区修订：最终系统为 STM32F103C8T6 + ESP-01S AT/TCP + Android；HarmonyOS 暂停。本轮没有发布新 GitHub Release。目录中的 v0.3.1/v0.3.0 名称为既有归档名称，组件可以独立版本化。

## 有效入口

- `STM32控制工程/`：固件源码、固定依赖构建脚本、主机回归测试和当前硬件/协议说明。按该目录 README 构建后使用 `build-firmware/` 的产物及哈希记录。
- `仿生鱼安卓AP直连_v0.3.0_2026-09-06/Android工程/`：Android 源码，当前版本 0.3.2（versionCode 5）。设备页 AP 直连使用 Wi-Fi 专用 TCP Socket。
- 同级 `仿生鱼控制器_v0.3.0_AP直连.apk`：历史版本，不能当作本轮固定低速版本的产物。新 APK 以 Android `app/build/outputs/apk/debug/` 为准。
- `原始资料/`：板级输入资料，其中历史设想不覆盖当前代码和配置。

## 当前范围

一颗两相双极步进电机使用 TB6612 两个 H 桥，一路舵机，JY61P 姿态和 SSD1306 单页显示。按键暂不使用。不支持 N20、HarmonyOS/ESP32 WebSocket 或自定义 ESP 透明桥。旧透明桥保留在 STM32 `legacy/`，不参与当前构建/烧录。

## 验收状态

固定低速版本通过17/17 CTest和Arm交叉构建，BIN24,604字节；Android0.3.2/code5通过56/56单元测试和23/23 MuMu设备测试，lint0错误，APK20,389,118字节。最终产物及哈希见STM32 build-firmware/build-info.json和Android验证记录。

默认推进允许固定低速连续运行：TB6612 10% PWM，每 50 ms 四拍换相；STOP 和失联释放两相。安卓仅保留前进/停止与舵机控制，RPM 均显示不可测。ESP AT 1.7.4 和当前 115200/8N1/无流控参数已由用户回包确认。实际转动、温升、完整 TCP 链路及传感器显示仍待实板验收。
